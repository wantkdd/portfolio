## GitHub 근거 보완

- 5개 프로젝트의 저장소·본인 PR·관련 구현·당시 CI를 대조했습니다. 출처와 확인 경계는 [콘텐츠 근거](content-evidence.md)에 기록했습니다.
- 사이트에 노출한 공개 GitHub URL **30개 모두 로그인 없는 HTTP HEAD 요청에서 200**을 반환했습니다. CI 로그 보관 만료 등 세부 하위 자료의 접근까지 보장하는 검사는 아닙니다.
- PLOG 측정 PDF의 실제 문서 페이지가 11페이지(인쇄 표기 8페이지)임을 텍스트 추출로 확인하고 링크를 수정했습니다.
- 새 문구에 맞춰 한글 서브셋을 갱신했습니다. 112,900바이트이며 소스에 쓰인 모든 한글 글리프가 포함됐습니다. 새 런타임 의존성이나 클라이언트 효과는 추가하지 않았습니다.
- 1440px·390px·320px에서 담당 범위, 근거 링크, 긴 설명과 비교표를 시각 검수했습니다. 캡처는 `.omx/artifacts/content-revision/`에 있습니다.
- 외부 프로젝트 테스트는 새로 실행하지 않았습니다. 과거 CI 성공, PR 작성자의 실행 보고, 테스트 코드 존재, 원본 PDF 측정값을 구분했습니다. 실기기 검사와 공개 배포도 이번 작업에 포함하지 않았습니다.
- 사용자 확인 대기: PLOG 인덱스·부하 측정 원본 파일, 실제 서비스 사용/피드백, 추가 리더십 결과. 해당 내용을 추정해서 추가하지 않았습니다.

## 모바일 Lighthouse — 포인터 효과 추가 시점

Lighthouse 12.8.2, 기본 모바일 시뮬레이션, 로컬 `next start`, 별도 Chrome 프로필에서 측정했습니다. 이미지는 서버 최적화 캐시가 있는 상태입니다. 배포 환경이나 실제 방문자 측정값은 아닙니다.

| 항목 | 최종 결과 |

| Performance | **95** |
| Accessibility | **100** |
| Best Practices | **100** |
| SEO | **100** |
| First Contentful Paint | 0.8초 |
| Largest Contentful Paint | 2.9초 |
| Speed Index | 0.8초 |
| Total Blocking Time | 31ms |
| Cumulative Layout Shift | 0 |
| 측정된 전송량 | 363KiB |

첫 측정은 성능 88점이었습니다. 첫 화면 진입 효과의 불투명도 애니메이션을 없애 콘텐츠를 즉시 표시하고, 핵심 배경 이미지에 높은 로딩 우선순위를 적용했습니다. 가시 텍스트와 접근성 이름의 불일치도 수정했습니다. 전송량에는 클릭 후 내려받는 PDF와 방문하지 않은 상세 경로가 모두 포함되지는 않습니다.

마우스 인터랙션 추가 후에도 성능 95점과 나머지 100점을 유지했습니다. 입력 효과는 각 영역의 포인터 이벤트를 RAF 한 번으로 묶으며, React 상태를 매 프레임 갱신하지 않습니다. 빛은 고정된 그라디언트의 transform/opacity만 바꾸고, 배지와 아이콘 아래에 배치했습니다.

보고서와 화면 캡처는 로컬 `.omx/artifacts/portfolio/`에 있습니다. `lighthouse-pointer-mobile.report.html`이 마우스 인터랙션을 포함한 최종 보고서이며, `lighthouse-mobile-before.report.html`은 첫 개선 전 결과입니다. 이 작업 폴더는 Git에 포함되지 않습니다.

## 확인 범위

실제 iOS Safari·Android 기기 및 외부 배포 환경에서는 아직 확인하지 않았습니다. Playwright WebKit 검사는 실제 Safari 앱 검증과 구분합니다. 자동 접근성 검사가 완전한 수동 접근성 검수를 대체하지는 않습니다. Lighthouse 수치는 포인터 효과 추가 시점의 기록이며, 이후 반응형 CSS 수정에 대해서는 기능·배치 검사를 수행했습니다. LCP 2.9초는 추가 개선 여지가 있으며, 공개 배포 후 네트워크·CDN 환경에서 다시 측정할 수 있습니다.
